# Examples

Runnable Mastra apps on Loams, against Loams on loopback or over a tailnet. Never a public
endpoint. Every `@mastra/*` version is exact.

| Example | What |
|---|---|
| [`quickstart-postgres`](quickstart-postgres) | Storage, vectors and memory on Loams Postgres (`@mastra/pg`) |
| [`quickstart-qdrant`](quickstart-qdrant) | Storage on Loams Postgres, vectors on the Loams Qdrant gateway (`@mastra/qdrant`) |
